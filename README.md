# EDIE WEB PREVIEW v2.1 — Interactive Intelligence Workspace

Public **static DEMO** for GitHub Pages. No backend, API, network requests, credentials, cookies, browser storage, personal data, or authentic market data. Gigantum and ARJUM remain NOT_CONNECTED. EDIE production FINAL_GATE remains BLOCK.

## Improvements over v2
- Control Tower: clickable alert/source policy explanations.
- Market Intelligence: timeframe UI selector with explicit synthetic-data disclaimer.
- Stock Intelligence: provenance and risk-policy explanations.
- Engine Center: locked master governance information.
- Broker Flow: broker selection UI, without actual records.
- Explicit CSS hidden behavior and mobile-responsive controls.

## Publish
Upload **index.html**, **app.js**, and **styles.css** to the root of the public GitHub Pages preview repository. Keep the operational repository private. Do not upload handoff archives or EDIE runtime.

## Limits
All data/graphs are DEMO. No scanner executes, no scores or investment recommendations are produced. No state persists. Public GitHub Pages is not suitable for operational EDIE.
